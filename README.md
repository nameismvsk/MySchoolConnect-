# 📘 MySchoolConnect

**MySchoolConnect** is a role-based school management system built in **Java**. It enables secure logins for principals, teachers, students, and parents, with controlled access to academic data like syllabus completion and subject details.

---

## 🚀 Features

- 🔐 Role-based login system (Principal, Teacher, Student, Parent)  
- 📚 Teachers can update syllabus completion status  
- 👀 Principals can view syllabus status but cannot modify it  
- 🧑‍🏫 Teacher dashboard with subject and syllabus details  
- 🧪 Input validation using Java regex and `equalsIgnoreCase()`  
- 🧠 Modular design for future expansion (attendance, grading, etc.)
